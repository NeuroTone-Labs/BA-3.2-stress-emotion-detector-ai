# BA-3.2-stress-emotion-detector-ai
AI stress coach. Using your webcam, keyboard, and voice recognition, it detects emotional states and stress in real-time, offering personalized solutions to help you feel calmer and more focused
## Dataset

This project uses the Multimodal Mental Health Assessment Dataset
from Kaggle.

The dataset is used for training and testing the machine learning
components of the project.

The full dataset is not included in this GitHub repository. It is
stored locally because of dataset size and usage restrictions.

### Dataset Source

Kaggle:
https://www.kaggle.com/datasets/zara2099/multimodal-mental-health-assessment-dataset
